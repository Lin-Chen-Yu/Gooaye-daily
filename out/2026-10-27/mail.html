英文招股文件截圖，反白「approximately 5% to 7% of our revenue」：公司估計截至 2026/9/30 的前九個月，約 5%–7% 營收來自事後才發現違反使用政策或商業條款的客戶；8、9 月已加強偵測與執法，預期比例會下降，但對營收和成長的衝擊時點與幅度不確定。

講解

圖上沒寫公司名，但這段文字出自 Anthropic 10/26 送交 SEC 的 S-1 公開說明書（IPO 用的申報文件）。重點在會計處理：服務提供時就認列營收，偵測、調查到停權要時間，所以在被抓到之前那段，違規客戶付的錢已算進營收。文件說這「在業界很常見」，但比例未來會下降。

為什麼值得注意：AI 模型商營收成長極快（第三方整理 S-1：2026 上半年營收約 163 億美元，年增約 13 倍），投資人會問這成長有多少「不可持續」。5%–7% 意味著有一塊營收是公司自己預告會主動砍掉的；而 8、9 月才加強執法，代表第四季後的數字才看得出影響。「違規」具體指哪些行為，截圖段落未說明，我也沒查到 S-1 的逐項定義，不宜自行推測。另外 5%–7% 本身是估計值，文件明說需要判斷、會隨偵測方法改變而調整。

同一份文件其他第三方摘要提到的風險：前五大客戶約占前九個月營收 25%（單一客戶未超過 10%），客戶集中度也是被討論的點。

OpenRouter 製圖「Anthropic tokens have surged」：6/1–10/24 OpenRouter 上 Anthropic 模型每日 token 用量，7 日均線從夏天約 0.6T/日，在 9 月下旬 Opus 5.5、Sonnet 5.5、Haiku 5.5 陸續上線後衝到約 2.2T/日，單日最高接近 3T，約是原本的 3.5 倍；新增量主要來自 Sonnet 5.5（橘色）與 Haiku 5.5（黃色），舊模型用量反而萎縮。

講解

OpenRouter 是 API 聚合平台：開發者用一組 API 就能切換各家模型，它能看到經過自己平台的流量，所以這張圖反映的是「OpenRouter 上的」用量，不是 Anthropic 全部的用量（大企業多直接接 Anthropic API 或經雲端商），代表性有限，比較像開發者端的風向球。

時間軸對得上：查得 Opus 5.5 於 9/22、Sonnet 5.5 於 9/28、Haiku 5.5 於 10/7 推出，且新版降價（Opus 5.5 據報比 Opus 5 便宜約 40%，Sonnet 5.5 最多便宜 30%）。降價通常會刺激用量，所以 token 暴增不必然等於營收等比例暴增——單價降了，量要漲更多才補得回來。和 #6509 放在一起看：一邊是用量動能強，一邊是公司承認有一塊營收來自違規客戶、正在清理，兩者是解讀 Anthropic IPO 時的正反兩面。股癌兩則都沒附文字評論，以上是我的脈絡補充，非他的觀點。
