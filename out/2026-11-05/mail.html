講解

發生什麼事：源頭是彭博 11/4 的報導（匿名知情人士），9to5Mac、MacRumors 等轉述。重點：蘋果部分工程師每天能花在 AI 模型（員工可用 Claude、ChatGPT、Gemini 等）上的額度，10 月已從 300 美元降到 200 美元；接下來「計畫」對部分工程團隊再降，可能低到 100 美元。另外報導提到許多非工程部門本來就只有 100 美元，部分非工程團隊甚至被考慮降到 25 美元；有些團隊被鼓勵改用較便宜的模型或在裝置上跑的本地模型。要特別注意：100 美元是「計畫／可能」，尚未定案；報導也指出其實少有員工真的用滿 300 美元，所以能省多少不明；資深主管可核准例外。媒體把這解讀為新任 CEO John Ternus 的成本控管動作，員工擔心是更大規模撙節甚至裁員的前兆。

這個「每日額度」是什麼：AI 程式助理（例如 Claude Code 這類代理型工具）是依 token 計費，模型讀進的程式碼和寫出的內容都算錢。代理型工具會反覆讀整個專案、自己跑多輪，一個工程師一天燒掉數十到上百美元並不罕見。乘上上萬名工程師、一年 250 個工作天，就是數億美元等級的帳單，這就是主委說「帳單大家都扛不住」的意思。

財報數字：9to5Mac 確認蘋果 FY2026 研發費用年增 32%，約 458 億美元，原因包含基礎設施與 AI 成本。貼文引的「營業費用增 22% 至 755 億美元、占營收 16%」出自 Investing.com，我查到的轉述文章沒有提及，這次未能獨立核實。

主委的延伸與需留意之處：「台系業者也在省」「博通只有特殊 clearance 員工能隨便用」是主委轉述的說法，他自己也標了「有一說」，我查到的報導都沒有提到博通，請當傳聞看待。同類案例確實存在：9to5Mac 提到 Accenture 把公司出錢的 Claude 額度砍到每人每月 29 美元。至於「往地端走」：指把推論從雲端 API 移到自家伺服器或終端裝置（on-device）上的開源／自研模型，邊際成本低、資料不外流，報導也確實提到蘋果鼓勵部分團隊用本地模型；但地端模型能力目前普遍不如頂尖雲端模型，是否真的形成大趨勢仍待觀察。投資意涵上，若企業端開始控管 token 用量，對以 API 營收為主的模型公司是逆風，對推論硬體（地端伺服器、AI PC／手機 NPU）可能是順風，但單一報導還不足以下定論。
